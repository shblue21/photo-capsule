# Powers used in this project

Kiro IDE registry Power: **Design System Power**, by AWS, activated as `design-system-scaffold` on 2026-10-03.

It was installed through the Kiro Powers panel and activated with `kiro_powers`. Kiro loaded the design-system and heuristic-review guidance, read our initial EJS views and wrote `docs/design-power-review.md`. Its recommendations informed upload progress, inline feedback, native dialog controls and focus indicators.

To reproduce, locate Design System Power in the Kiro Powers registry, install it, and ask Kiro to run a heuristic review of `src/views`. No cloud account is required for this review.

Custom package: `powers/photo-capsule-review/` was installed from its local folder and activated in Kiro IDE on 2026-10-03. Its script ran typecheck and 49 tests and its report template produced `docs/verification/power-review.md`. See `docs/verification/runtime-results.md`.
